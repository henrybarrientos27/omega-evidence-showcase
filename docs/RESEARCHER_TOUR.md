# Five-minute evidence tour

This repository is a public evidence record, not an installable distribution.

1. **Inspect the [sample review sheet](../assets/review-sheet.png).** This
   historical output illustrates an event-review queue for the public TIC case
   study. It is not a current OMEGA Pro UI or a new detection result.
2. **Read the [benchmark conclusion](../BENCHMARK_SUMMARY.md).** Distinguish
   deterministic injections from the two real-catalog positives and inspect
   failures. The benchmark does not establish broad detector superiority.
3. **Check [the verification record](../evidence/verification.json).** Hashes
   and completion checks establish the recorded artifacts' integrity; they do
   not turn a limited cohort into a population-wide result.
4. **Read [the published case study](https://doi.org/10.3847/2515-5172/ae9b07).** Its scientific claims and
   unresolved companion class are separate from the software's performance.
5. **Give feedback.** Identify which evidence, label, or reproducibility detail
   would help you decide whether a private workflow demonstration is useful.
   Use the researcher-feedback issue template with public examples only.

No researcher endorsement, independent adoption, or measured review-time saving
is implied. For permissions, see [RIGHTS.md](../RIGHTS.md).
